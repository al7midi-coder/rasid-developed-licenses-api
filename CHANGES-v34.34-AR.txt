راصد API v34.34 — Central Login Fix
التاريخ: 2026-08-10

التعديل محصور في المصادقة فقط فوق v34.33:
- إضافة POST /api/v1/auth/login.
- التحقق من البريد أو اسم المستخدم وكلمة المرور مباشرة من ورقة Users عبر Google Sheets API باستخدام حساب الخدمة.
- لا يتم إعادة Password إلى الواجهة نهائياً.
- احترام IsActive ومنع الحسابات غير النشطة.
- دعم الصلاحيات الأساسية وحقول المشروع/الإدارات في بيانات المستخدم المعادة.
- إبقاء password-reset/request و password-reset/confirm كما هما.
- إضافة /api/v1/auth/login إلى المسارات العامة المسموحة قبل Hook حماية الكتابة.

مهم:
هذه الحزمة تصلح جهة الـAPI بالكامل. لكي تستخدم واجهة Firebase تسجيل الدخول المركزي يجب أن تستدعي POST /api/v1/auth/login بدلاً من المقارنة المحلية مع demoPassword.
